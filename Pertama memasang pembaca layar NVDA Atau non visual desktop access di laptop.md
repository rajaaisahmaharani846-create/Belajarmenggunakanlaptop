# Panduan Lengkap Instalasi dan Pengaturan NVDA untuk Navigasi Layar

Panduan ini berisi langkah-langkah praktis mulai dari mendapatkan aplikasi pembaca layar NVDA (NonVisual Desktop Access), proses instalasi di sistem operasi Windows, konfigurasi awal, hingga cara menggunakan perintah dasar untuk navigasi layar secara mandiri.

---

## 1. Cara Mendapatkan Aplikasi NVDA
* Buka browser di perangkat Anda, lalu kunjungi situs resmi [nvaccess.org](https://www.nvaccess.org/).
* Pada halaman utama situs, cari dan klik tombol **Download** (Unduh) untuk mendapatkan file installer versi terbaru.
* Tunggu beberapa saat hingga proses pengunduhan file installer berformat `.exe` selesai tersimpan di komputer Anda.

---

## 2. Langkah-Langkah Instalasi NVDA
1. Buka folder tempat penyimpanan file yang telah diunduh (biasanya berada di folder *Downloads*).
2. Klik dua kali pada file installer NVDA untuk mulai menjalankan program pemasangan.
3. Jika muncul jendela konfirmasi atau peringatan keamanan dari sistem Windows (*User Account Control*), klik tombol **Yes** untuk memberikan izin.
4. Baca ketentuan lisensi yang tertera, lalu centang kotak pilihan **I agree to the license agreement**.
5. Klik tombol **Install NVDA on this computer** untuk memasang aplikasi ke dalam sistem penyimpanan perangkat Anda.
6. Pada opsi tambahan yang muncul, centang bagian *Use NVDA on the Windows logon screen* (agar NVDA aktif di layar login) dan *Create a desktop icon and shortcut key* (untuk membuat jalan pintas di layar utama).
7. Klik **Continue**, tunggu proses penyalinan berkas hingga selesai, lalu klik **OK** atau mulai ulang perangkat jika diminta.

---

## 3. Konfigurasi Awal dan Pengaturan Navigasi
Saat aplikasi pertama kali dijalankan setelah instalasi selesai, jendela pengaturan awal (*Welcome Dialog*) akan otomatis muncul untuk menyesuaikan preferensi navigasi Anda:
1. **Keyboard Layout (Tata Letak Keyboard):** Pilih tata letak yang sesuai dengan perangkat yang Anda gunakan, yaitu **Desktop** (jika menggunakan keyboard yang memiliki tombol *NumPad* terpisah) atau **Laptop** (jika menggunakan keyboard standar laptop).
2. **NVDA Modifier Key (Tombol Pengubah):** Tentukan tombol utama yang akan digunakan bersama tombol navigasi lainnya. Umumnya diatur menggunakan tombol **Insert** atau **Caps Lock**.
3. **Automatic Startup:** Centang opsi *Automatically start NVDA after I log on to Windows* jika Anda ingin pembaca layar ini langsung aktif secara otomatis setiap kali komputer dinyalakan.
4. Klik tombol **OK** untuk menyimpan seluruh pengaturan dan membuat NVDA siap digunakan untuk navigasi layar.

---

## 4. Perintah Dasar untuk Navigasi Layar
Setelah pengaturan selesai, NVDA dapat digunakan untuk menavigasi elemen-elemen di layar komputer menggunakan kombinasi tombol berikut:
* **Tombol Panah (Arrow Keys):** Digunakan untuk membaca teks baris per baris atau berpindah antar menu.
* **Tombol Kontrol (Ctrl):** Menekan tombol ini secara singkat berfungsi untuk menghentikan sementara suara bacaan (*speech*) saat NVDA sedang berbicara.
* **NVDA + N:** Membuka menu utama NVDA untuk mengakses pengaturan suara (*synthesizer*), kecepatan bicara, dan preferensi lainnya.
* **NVDA + Q:** Digunakan untuk keluar (*Quit*) atau menutup aplikasi NVDA dari sistem.
