# Panduan Lengkap Mendapatkan dan Memasang Mesin Suara Tambahan di NVDA

Panduan ini berisi langkah-langkah praktis mulai dari mendapatkan file pengaya mesin suara tambahan (*synthesizer*/*vocalizer*), cara memasangnya ke dalam aplikasi NVDA, hingga mengaktifkannya untuk navigasi suara.

---

## 1. Cara Mendapatkan Mesin Suara Tambahan
* Kunjungi situs resmi repositori pengaya di [addons.nvda-project.org](https://addons.nvda-project.org/) untuk mencari ekstensi mesin suara atau *vocalizer* yang kompatibel dengan NVDA.
* Unduh file pengaya berformat `.nvda-addon` yang diinginkan agar tersimpan di perangkat komputer Anda.
* Tekan tombol **Windows + E** secara bersamaan pada keyboard untuk membuka jendela **File Explorer**.
* Di panel sebelah kiri File Explorer, klik folder **Downloads** (Unduhan) tempat file yang baru saja diunduh tersimpan untuk memastikan keberadaannya.

---

## 2. Langkah-Langkah Memasang Mesin Suara di NVDA
1. Buka aplikasi NVDA yang sudah terpasang di komputer Anda.
2. Tekan kombinasi tombol **NVDA + N** pada keyboard untuk membuka menu utama NVDA.
3. Arahkan kursor ke menu **Tools** (Alat), lalu pilih opsi **Manage add-ons** (Kelola add-on).
4. Di jendela pengelolaan add-on yang muncul, klik tombol **Install** (Pasang) di bagian bawah.
5. Masuk ke folder **Downloads** melalui jendela pencarian tersebut, lalu cari dan pilih file `.nvda-addon` mesin suara tambahan yang sudah diunduh sebelumnya dan klik **Open** (Buka).
6. Klik **Install** pada jendela konfirmasi yang muncul untuk melanjutkan proses pemasangan.
7. Setelah instalasi selesai, NVDA akan meminta izin untuk memulai ulang (*restart*) agar pengaya baru dapat dimuat. Klik **Yes**.

---

## 3. Mengaktifkan dan Mengatur Mesin Suara
Setelah NVDA aktif kembali setelah proses *restart*, ikuti langkah berikut untuk menggunakannya:
1. Buka menu pengaturan suara cepat dengan menekan kombinasi **NVDA + Control + V** (atau melalui **NVDA + N** > **Preferences** > **Settings** > kategori **Speech**).
2. Pada bagian pilihan *Synthesizer*, klik tombol *Change* untuk melihat daftar mesin suara yang tersedia.
3. Pilih mesin suara tambahan atau *vocalizer* yang baru saja Anda instal.
4. Sesuaikan parameter pendukung seperti kecepatan bicara (*rate*), tinggi nada (*pitch*), dan volume sesuai kenyamanan Anda.
5. Klik tombol **OK** untuk menyimpan seluruh pengaturan dan mesin suara siap digunakan.
