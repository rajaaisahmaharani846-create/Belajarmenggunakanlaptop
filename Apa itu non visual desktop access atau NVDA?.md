NonVisual Desktop Access (NVDA) adalah perangkat lunak pembaca layar (screen reader) gratis dan bersumber terbuka (open-source) yang dirancang khusus untuk sistem operasi Microsoft Windows. Aplikasi ini berfungsi untuk menerjemahkan teks dan elemen visual di layar komputer menjadi umpan balik suara (speech) atau output huruf braille, sehingga tunanetra maupun individu dengan hambatan penglihatan dapat mengoperasikan komputer secara mandiri.
Sebagai salah satu teknologi asistif yang paling populer di dunia, NVDA mendukung berbagai aplikasi harian seperti peramban web (browser), klien surel, program pengolah kata, hingga manajemen berkas sistem. Perangkat lunak ini pertama kali dikembangkan oleh NV Access, sebuah organisasi nirlaba yang didirikan oleh Michael Curran dan Jamie Teh pada tahun 2006, dengan misi utama untuk memastikan aksesibilitas teknologi informasi tanpa batasan biaya bagi komunitas tunanetra global.
